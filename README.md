## ✨ Features & Architecture

### 1. Monumental Architectural Aesthetics
- **Warm Editorial Typography:** High-contrast headings paired with modern sans-serif body and monospace tags.
- **Architectural Arched Showcase:** Custom arch frame with rotating circular stamp badge (`FRONT-END · REACT · NEXT.JS · TAILWIND · FAST-NUCES · `).
- **Blueprint Grid & Paper Textures:** Subtle architectural line grids and soft shadows.
- **Triple Theme System:**
  - **Atelier (Default):** Warm, serene archival paper (`#FAF7F2`) with terracotta clay accents (`#B85D3B`).
  - **Nocturne:** Obsidian dark mode (`#0F0E0D`) with glowing warm highlights.
  - **Terminal:** Matrix emerald theme (`#0A0F0D`) with code syntax accents for CS environments.

### 2. Interactive Sections
- **Infinite Moving Marquee Ticker:** Seamless horizontal track with tech keywords and decorative stars.
- **Selected Work & Filterable Gallery:**
  - *BurgerCraft* — Interactive Food Builder & Customizer (React + Tailwind).
  - *FAST-NUCES Classroom Hub* — Student portal with timetable & GPA predictor (Next.js).
  - *LuxeStore* — Headless e-commerce with slide-over cart drawer (Next.js).
  - *AlgoVista* — Sorting algorithm visualizer with side-by-side C++ logic (JavaScript + Canvas).
  - *DevPulse* — Luxury editorial portfolio engine.
  - *Matias UI* — Accessible Tailwind component kit.
- **Project Modal Dialog:** Detailed modal showing challenge, solution, metrics, features, and direct links.
- **Interactive Component Lab:** Live interactive previews of UI components with copyable Tailwind CSS & React JSX snippets.
- **Design Blueprint vs Live Code Slider:** Interactive draggable before/after comparison revealing how a schematic wireframe translates into production React code.
- **FAST University Lahore & Academic Journey:** Detailed narrative combining academic CS rigor (C++, pointers, algorithms) with modern front-end craft.
- **Technical Arsenal / Toolkit:** Categorized tech stack with proficiency levels.
- **4-Stage Engineering Process:** Blueprint & Architecture → Semantic DOM → Tailwind Reactive State → Optimization & Launch.
- **Interactive Contact Form & Direct Inquiries:** One-click copy for email, WhatsApp, GitHub, LinkedIn, and FAST Lahore location.

## 🚀 Getting Started

### 1. Start Development Server
```bash
cd /Users/mac/.gemini/antigravity/scratch/abdul-baseer-portfolio
npm run dev
```
*(Or simply type `run` in your terminal!)*

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 2. Build for Production
```bash
npm run build
```

### 3. Run Production Build
```bash
npm run start
```
